# ToUpList-API-Whitelist

## 公开列表 API 白名单申请

本文档说明如何为 `touplist` 插件（RW-HPS 核心）及 `touplistru` 插件（Rukkit 核心）申请上列表 API 白名单。

## 申请格式

将以下信息按格式填写后提交：

```json
[
  { "name": "服务器A", "IP": "x.x.x.x" },(如果后面还有服务器就要写逗号)
  { "name": "服务器B", "IP": "x.x.x.x" }(如果后面没有服务器就不要写逗号)
]
```

## 什么是登记IP

登记 IP 指的是**服务端所在主机的真实 IP 地址**。

如果你的服务器运行在本地（如家用电脑），请填写本地公网 IP，而非代理或穿透服务的 IP。

> 注意：whitelist 文件与插件本身无关，两者不要混淆。
>
> 同时：由于大多数环境都为共享IP所以会出现IP变动的情况，请不要将原来的IP过快删除。而是添加新地址并留有原IP变动时间，否则如果会变回去需要重复申请，费时费力。
>
> 
## 同步大约多久

需要维护者进行手动同步，时间不固定，但大多数同步间隔为3天内(依据有无空闲时间而定)。

## 稳定性

一般维护时间为周一,三,五,六 中午11:00-中午11:30 晚9:00-晚10:00 

恶性bug会直接紧急停止并维修，会发布更新公告。

## 为什么不是直接开放？

目前 API 的过滤机制（违禁词过滤、广告过滤、访问限制等）尚未完善，暂时通过白名单制度进行管理，避免以下问题：

 - 恶意刷 API 导致列表服务不稳定

 - 违规内容通过 API 传播

白名单制度虽然不完美（“防君子不防小人”），但在当前阶段是相对可行的方案。如果你在[ToUpList · 服务器守约监控](http://103.217.186.229:19238/reg)中遇到违禁词或广告内容，可以删除进行合理处理，并保留相关证据。

如有其他问题，欢迎提交 Issue 联系维护者。

## 免责声明

本 API 由第三方维护，不保证服务绝对稳定。使用过程中可能偶发延迟或短暂不可用，属正常情况，维护者会尽力保障服务可用性。

本 API 仅供个人服主测试使用，不建议大型公开服务器长期依赖。高频请求可能导致服务拥堵，影响其他用户正常使用。

# ToUpList‑API‑Whitelist 隐私政策

> 
> 生效日期：2026‑09‑04

本隐私政策适用于 **ToUpList API（touplist）公开列表服务**，服务仓库：[https://github.com/Dongdong192/ToUpList](https://github.com/Dongdong192/ToUpList)‑API‑Whitelist/tree/main
凡申请白名单、调用、使用本 API 服务，即代表您同意本隐私政策全部条款。

本政策中提及的**服务登记信息**：指服主提交用于服务器上架公开列表的相关数据，其中不含身份证、手机号等现实身份信息。

重要告知：
当你提交白名单申请，**所有被 API 获取到的服务器相关信息（服务端主机真实公网 IP 地址、服务器名称、MOTD、状态、玩家、协议、上报版本号、是否密码 等）均会对外提供，可被所有能够访问监控接口的人员获取**，请充分知悉风险后再提交申请。

## 1. 收集的信息与获取方式

ToUpList API 会收集、处理以下由服主主动提交以及服务运行产生的信息：

1. **白名单申请提交信息**

- 服务器名称
- 服务端主机真实公网 IP 地址

> 
> 注意：填写为服务器运行主机真实公网 IP，家用环境填写家庭公网 IP，请勿填写穿透 / 代理 IP。

2. **服务器上报运行信息**

- 服务器 MOTD（展示地图名称）
- 服务器是否设置密码
- 服务器在线运行状态
- 服务端版本号、协议版本号
- 服务端所在主机真实公网 IP 地址

3. **访问与运行日志**
API 服务会留存访问日志，包含访问 IP、访问时间、请求路径、访问频次，用于反滥用、故障排查、恶意行为识别。

> 
> 注意： whitelist 白名单文件仅用于 API 准入校验，和插件本体配置相互独立，请不要混淆。

## 2. 信息使用目的

收集以上信息仅用于下述用途：

- 提供公开列表上架 API 签名服务，使你的铁锈战争服务器可以与官方列表API沟通
- 白名单准入校验，拦截未授权访问
- 防范恶意刷接口、滥用服务，保障整体服务稳定性
- 排查故障、修复恶性 BUG、服务运维维护
- 识别广告、违规内容，过滤违禁信息
- 处理用户 Issue、反馈与问题咨询
- 统计服务运行情况

## 3. 信息共享与对外提供

- **API 所能获取到的全部服务器数据，会向所有可访问监控接口的人员提供。**
- 不会将收集到的信息用于商业售卖。
- 仅在收到法律法规要求、官方有权机关指令的情况下才会对外提供对应信息。

## 4. 信息变更、删除

1. **IP发生变动**：请勿直接删除旧IP，新增一条新IP记录，保留旧IP，并在名称栏填写对应的变更时间。等待5天确认无进一步变动后，再通过PR删除原有IP。
> 注意：长期留存废弃IP有被他人恶意滥用的风险，可能造成你的账号被连带误封禁；只要IP登记在你的名下，你就需要承担对应的使用责任。

2. **需要移除服务器记录**：提交 GitHub Issue，写明服务器名称、对应IP，同时附上权属证明（例如当初添加记录的PR链接），证明为本人操作，交由项目维护者处理。
