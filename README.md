# ToUpList-API-Whitelist

## 公开列表 API 白名单申请

本文档说明如何为 `touplist` 插件（RW-HPS 核心）及 `touplistru` 插件（Rukkit 核心）申请上列表 API 白名单。

## 申请格式

将以下信息按格式填写后提交：

```json
[
  { "name": "服务器A", "IP": "x.x.x.x" },(如果后面还有服务器就要写逗号)
  { "name": "服务器B", "IP": "x.x.x.x" }(如果后面没有服务器就不要写逗号)
]
```

## 什么是登记IP

登记 IP 指的是**服务端所在主机的真实 IP 地址**。

如果你的服务器运行在本地（如家用电脑），请填写本地公网 IP，而非代理或穿透服务的 IP。

> 注意：whitelist 文件与插件本身无关，两者不要混淆。
>
> 同时：由于大多数环境都为共享IP所以会出现IP变动的情况，请不要将原来的IP过快删除。而是添加新地址并留有原IP变动时间，否则如果会变回去需要重复申请，费时费力。
>
> 
## 同步大约多久

需要维护者进行手动同步，时间不固定，但大多数同步间隔为3天内(依据有无空闲时间而定)。

## 稳定性

一般维护时间为周一,三,五,六 中午11:00-中午12:00 晚9:00-晚10:00 

恶性bug会直接紧急停止并维修，会发布更新公告。

## 为什么不是直接开放？

目前 API 的过滤机制（违禁词过滤、广告过滤、访问限制等）尚未完善，暂时通过白名单制度进行管理，避免以下问题：

 - 恶意刷 API 导致列表服务不稳定

 - 违规内容通过 API 传播

白名单制度虽然不完美（“防君子不防小人”），但在当前阶段是相对可行的方案。如果你在[ToUpList · 服务器守约监控](http://103.217.186.229:19238/reg)中遇到违禁词或广告内容，可以删除进行合理处理，并保留相关证据。

如有其他问题，欢迎提交 Issue 联系维护者。

本 API 仅供个人服主测试使用，不建议大型公开服务器长期依赖。高频请求可能导致服务拥堵，影响其他用户正常使用。
